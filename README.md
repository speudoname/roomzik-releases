# Roomzik releases

Installers for **Roomzik**, the Mac app that puts any student's screen on the projector.

Download: https://roomzik.com

- Apple silicon: [Roomzik-arm64.dmg](https://github.com/speudoname/roomzik-releases/releases/latest/download/Roomzik-arm64.dmg)
- Intel: [Roomzik-x64.dmg](https://github.com/speudoname/roomzik-releases/releases/latest/download/Roomzik-x64.dmg)

macOS 13 or later. The app's code is private; this repository only holds what the download page links to.

Roomzik includes UxPlay (GPL-3.0, https://github.com/FDH2/UxPlay) as a separate program, and GStreamer (LGPL). See Roomzik.app/Contents/Resources/licenses.
